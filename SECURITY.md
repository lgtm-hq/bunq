# Security

Follow the [LGTM HQ security policy][policy] for private reporting and response
expectations. If repository private reporting is unavailable, use the fallback
contact in that policy. Never report a vulnerability with real credentials or
banking data in a public issue.

This repository has no released versions yet. No production banking deployment
has been accepted. Supported release lines will be stated here before the first
release; this foundation does not claim an audited or enabled service.

Reports should use sandbox reproduction steps and redacted payloads. Omit API
keys, installation/session tokens, signing keys, full account/card identifiers,
PINs, CVC values and personal transaction text. If credentials have been exposed,
revoke them through the bank's controls before sharing reproduction evidence.

[policy]: https://github.com/lgtm-hq/.github/blob/main/SECURITY.md
